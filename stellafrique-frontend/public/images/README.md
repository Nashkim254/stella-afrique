# Image Asset Map

Use `public/images` for static homepage and storefront assets.

Folders:

- `hero/`: large landing visuals
- `products/`: product cards and listing images
- `categories/`: circular category thumbnails
- `blog/`: blog or editorial cards
- `brands/`: partner and trust logos
- `ui/`: decorative section backgrounds and generic supporting assets

Current placeholders are SVGs so layout work can continue before final exports arrive.
Replace files in place to avoid updating component paths later.
